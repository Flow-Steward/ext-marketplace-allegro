# Flow Steward extension: Allegro

Connects Flow Steward workflows to the [Allegro REST API](https://developer.allegro.pl/).

- Every one of the 270 operations documented in the pinned Allegro specification
  (`tests/reference/allegro_api.json`, OpenAPI 3.0.0, SHA-256 `f82541bb…14b9`, downloaded
  2026-11-18) is a step, generated by `tests/reference/build_contracts.py`.
- Everyday steps: Test connection, Get all my offers, Update stock and prices, Get stock and
  price update results, Get orders, Get order events.
- Connections are Allegro or Allegro Sandbox accounts authorized with OAuth 2.0 (authorization
  code with PKCE). Flow Steward Core keeps, renews and stores the tokens; a step receives only
  the current access token.

Development: download `https://developer.allegro.pl/swagger.yaml` to
`tests/reference/sources/swagger.yaml` (not committed), then
`python3 tests/reference/extract_reference.py` and `python3 tests/reference/build_contracts.py`.
Tests: `python -m pytest -q` with the SDK wheel from `dev-wheels/`.
