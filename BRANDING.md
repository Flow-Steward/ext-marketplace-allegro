# Branding

`icon.png` is the Allegro mark (the orange "a") as Allegro's own developer portal shows it
for its pages, used only to identify this integration in Flow Steward.

## Source

- Product: Allegro, the online marketplace of Allegro.pl sp. z o.o. — <https://allegro.pl/>.
- Official asset: the site icon of Allegro's developer portal,
  <https://developer.allegro.pl/favicon.ico> (declared by the page as `<link rel="icon" href="/favicon.ico">`;
  an ICO file holding one 48 × 48, 32-bit image), downloaded 2026-11-18.
- SHA-256 of the source: `14746ef370c483e62142575c3f24d51453558454d07f078d7e56694475da3df8`.

allegro.pl itself answered 403 to a plain download and was not tried further. The portal's
`apple-touch-icon.png` answers 404. The Allegro wordmark the portal shows
(`logo-allegro-…` on a.allegroimg.com) is wide, not square, so the site icon is used instead.

## What was done

- The one image of the ICO file was written as PNG, pixel for pixel: same 48 × 48 size, same
  RGBA values, no scaling or editing (a format change only, needed because Flow Steward takes PNG).
- SHA-256 of `icon.png`: `e0b4c3549cb634e4adbecce09b88f05e16bdc0163947fd598bc14244051f339d`.
